### Issue with non-principal polarizations ###
##############################################
We trust the output we have produced so far, but the current code will never finish for big isogeny classes because of the issue described below.

The current code is based on intrinsic with the following dependencies:
    MaximalIntermediateIdeals --> AllMinimalIsogenies --> IsogeniesByDegree --> AllNonprincipalPolarizations
The problem is that AllMinimalIsogenies loops over ICM x ICM to compute the isogenies. This is extremely expensive.

We started refactoring the code using some intrinsics that we wrote in 2023 and used for the first round of computations started back then. This can be found in the branch `refactor_pols` of the repo.
The dependencies are
    RepresentativeMinimalIsogenies --> RepresentativeIsogenies --> AllNonprincipalPolarizations 
             DistinguishedPicBasis -->
             DistinguishedCosetRep --> 
Note that, in that branch, we moved all the relevant intrinsics in Isogenies.m and Polarizations.m and move the one we don't use in old_legacy.m
The advantage of this approach is that RepresentativeIsogenies loops only over WKICM x WKICM x WKCIM, which is much better!
But we believe that there is a bug: in RepresentativeIsogenies there an assert failing: we are trying to add something with the wrong degree! We could not figure out out to solve the problem during the conference.
